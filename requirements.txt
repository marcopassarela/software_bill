# A Vercel instala ESTE arquivo dentro do bundle da função Python. Tudo
# que estiver aqui vira tamanho de deployment, e cada deployment ocupa
# espaço na cota de Functions Storage (era isso que estava em 18,8 GB
# de 10 GB permitidos).

# Foram retirados daqui, de propósito:
#   - uvicorn[standard]: servidor local. Na Vercel quem executa o ASGI é
#     a plataforma. O extra "standard" ainda puxava uvloop, httptools e
#     watchfiles, que são binários grandes e completamente inúteis aqui.
#   - alembic: só roda migration na sua máquina (alembic upgrade head).
#   - pytest / httpx: só teste.
#   - redis: só é necessário com REALTIME_SSE_ENABLED=1, que não deve ser
#     ligado em serverless (ver backend/app/realtime.py).
#
# Para desenvolver localmente e rodar migrations, use:
#     pip install -r backend/requirements.txt
